```

assets/foto.jpg  fotografia de perfil
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `portfolio` ou `<utilizador>.github.io`).
2. Envie estes ficheiros para a raiz do repositório (branch `main`).
3. Em **Settings → Pages**, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)` e guarde.
4. Em 1–2 minutos o site fica disponível em `https://<utilizador>.github.io/<repositório>/`.

## Ver localmente

Abra `index.html` no navegador.
